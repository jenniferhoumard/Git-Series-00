## 3. Motivation to Learn Python, R and Git

- I want to develop strong skills in Python, R and Git because I am particularly interested in sports science, data analysis and using technology to better understand athletic performance.

- Outside of my studies, I have been developing a personal sports data project based on the training data recorded by my Garmin watch. The idea is to take information from my running, cycling and other training sessions and use Python to process, organise and prepare this data for further analysis.

- The processed data is then stored in a MySQL database, which gives me a structured way of keeping a large amount of training information. I connect this database to an n8n workflow and an OpenAI model so that I can ask questions about my training data in natural language instead of having to manually search through the database every time.

- For example, the long-term goal is to be able to ask questions about changes in my training, compare different periods, analyse performance trends and generate useful graphs or summaries from the information stored in the database. Learning Python and R more deeply will allow me to improve both the data-processing and statistical-analysis parts of this project and understand the methods behind the results rather than simply relying on automated tools.

- Git is equally important for me because as projects like this become larger, I need a reliable way to organise my code, keep a history of the changes I make, experiment without losing previous versions and eventually collaborate with other people. Becoming comfortable with Python, R and Git will therefore be useful not only for this personal project, but also for future projects in sports science, research and performance data analysis.
